## 🚀 Featured projects

### 🙏 [Clama](https://clama.me): *personalized prayer platform*
Users send a prayer request and get a personalized pastoral reply with Bible verses, generated with AI. The backend is being migrated from Django to **Java 27 + Spring Boot 4**: Spring Security with JWT in httpOnly cookies, Spring Data JPA, Flyway, db-scheduler as a job queue (replacing Celery + Redis), Mercado Pago payments, Testcontainers integration tests and contract replays against the legacy API.
`Java · Spring Boot · PostgreSQL · Flyway · Testcontainers · React`

### 🤝 [Bora](https://www.borajuntos.app): *group habit challenges*
Your group agrees on a healthy habit, posts proof every day and keeps each other on track. Contributions go through Pix with a flat fee. It has a REST API with JWT auth, cron jobs that close challenges and pick the winners, Mercado Pago integration and S3 storage for the daily proof photos.
`TypeScript · NestJS · Prisma · PostgreSQL · AWS S3 · React`

More Java: [VirtualThreads](https://github.com/PedroVasconcelos18/VirtualThreads) (exploring Java 21 virtual threads) · [NeetCode submissions](https://github.com/PedroVasconcelos18/neetcode-submissions) (algorithms in Java)
